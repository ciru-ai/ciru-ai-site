⚙️ STEP 1: PREPARE THE CLOWN CAR (HOST SETUP) ⚙️

1

Kernel Parameters — The Magic Spells 🧙‍♂️

Your computer needs some magic kernel parameters to let the GPU do its clown tricks. These tell your computer to share memory with the GPU — like sharing your lunch with a friend! 🍱

🚨 DO NOT USE linux-firmware-20251125! It's like giving your clown a whoopee cushion — it will crash and burn! 🔥 Check your version:
rpm -qa | grep linux-firmware

If you see 20251125, downgrade immediately:

# For Fedora 43:
mkdir -p ~/linux-firmware-downgrade
cd ~/linux-firmware-downgrade
wget -r -np -nd -A '*.rpm' https://kojipkgs.fedoraproject.org/packages/linux-firmware/20251111/1.fc43/noarch/
sudo dnf downgrade ./*.rpm
sudo dracut -f

Now add the magic kernel parameters:

# Add these to your GRUB_CMDLINE_LINUX in /etc/default/grub:
amd_iommu=off amdgpu.gttsize=126976 ttm.pages_limit=32505856
🤡 What do these do?
  • amd_iommu=off — Turns off the IOMMU. Makes things 5-12% faster! Like removing training wheels from your clown bike! 🚲
  • amdgpu.gttsize=126976 — Caps GPU memory to 124 GiB. That's a LOT of memory! 🧠
  • ttm.pages_limit=32505856 — Caps pinned memory to 124 GiB. More memory sharing! 🤝

Apply the magic and reboot:

sudo grub2-mkconfig -o /boot/grub2/grub.cfg
sudo reboot
The kernel parameter amd_iommu=off was discovered to be faster by a clown named Lars Urban (@urbanswelt). He's basically the Einstein of clown computing! 🧠🤡

🎪 STEP 2: BUILD YOUR CLOWN CAR (CREATE TOOLBOX) 🎪

2

Choose Your Clown Car Flavor! 🍦

There are different toolbox images, each with a different "flavor" of GPU backend. Pick one!

🎨 Flavor 🔧 Backend 📝 Notes
vulkan-radv Vulkan (Mesa RADV) Most stable! Like vanilla ice cream — always good! 🍦
vulkan-amdvlk Vulkan (AMDVLK) Fastest! But has a 2 GiB limit. Like a speed demon clown! 🏎️
rocm-7.2.4 ROCm 7.2.4 Recommended for performance! The big top of clown cars! 🎪
rocm-6.4.4 ROCm 6.4.4 Older but stable. Like a classic clown car! 🚗
⚠️ AVOID rocm7-nightlies for now — it has a bug that caps memory at 64GB. It's like a clown car that only fits 2 clowns! 😢

Create Your Toolbox!

Option A: Vulkan (RADV) — Best for compatibility, like a clown who gets along with everyone! 🤝

toolbox create llama-vulkan-radv \
  --image docker.io/kyuz0/amd-strix-halo-toolboxes:vulkan-radv \
  -- --device /dev/dri \
    --group-add video \
    --security-opt seccomp=unconfined

toolbox enter llama-vulkan-radv

Option B: ROCm 7.2.4 — Best for performance, like a clown on espresso! ☕🤡

toolbox create llama-rocm-7.2.4 \
  --image docker.io/kyuz0/amd-strix-halo-toolboxes:rocm-7.2.4 \
  -- --device /dev/dri \
    --device /dev/kfd \
    --group-add video \
    --group-add render \
    --group-add sudo \
    --security-opt seccomp=unconfined

toolbox enter llama-rocm-7.2.4

Check That Your GPU Is Working! 🎉

Inside your toolbox, run this to see if your GPU is doing its clown tricks:

llama-cli --list-devices

If you see your GPU listed, HONK HONK — you did it! 📯📯

🚀 STEP 4: MAKE THE PARROT TALK! (RUN INFERENCE) 🚀

4

Time to Talk to Your Parrot! 🦜💬

🚨 VERY IMPORTANT! Always use -fa 1 (flash attention) and --no-mmap on Strix Halo. Without these, your parrot might fall off its perch! 🦜💥

Server Mode — Runs an API server. Like a parrot that answers questions through a walkie-talkie! 📻

llama-server -m models/qwen3-coder-30B-A3B/BF16/Qwen3-Coder-30B-A3B-Instruct-BF16-00001-of-00002.gguf \
  -c 8192 -ngl 999 -fa 1 --no-mmap

CLI Mode — Chat directly in the terminal. Like talking to the parrot face-to-face! 🗣️

llama-cli --no-mmap -ngl 999 -fa 1 \
  -m models/qwen3-coder-30B-A3B/BF16/Qwen3-Coder-30B-A3B-Instruct-BF16-00001-of-00002.gguf \
  -p "Write a Strix Halo toolkit haiku."

Router Mode — Multi-model routing with a config file. Like having a whole flock of parrots and a manager! 🦜👔

llama-server --models-preset models.ini --host 0.0.0.0 --port 8080 --models-max 1 --parallel 1

What Do Those Flags Mean? 🤓

🔥 -fa 1 — Flash Attention. Makes things faster, like a clown on a pogo stick! 🤸
🚫 --no-mmap — No memory mapping. Prevents crashes on Strix Halo. Like wearing a helmet while juggling chainsaws! ⛓️
🎯 -ngl 999 — Put all layers on GPU. Maximum clown power! 💪
📏 -c 8192 — Context length. How much the parrot can remember! 🧠

🔧 TROUBLESHOOTING — WHEN CLOWNS FALL OFF THE UNICYCLE 🔧

Common Clown Problems & Solutions 🩹

🚨 Problem: Everything crashes and burns! 🔥
Solution: Check your linux-firmware version. If it's 20251125, downgrade it! See Step 1 above.
🚨 Problem: Your model won't load or runs super slow! 🐌
Solution: Make sure you're using -fa 1 and --no-mmap. These are like the clown's safety net! 🥅
🚨 Problem: llama-cli --list-devices shows nothing! 😱
Solution: Check your kernel parameters. Make sure amd_iommu=off and the other params are set. Also check that you passed --device /dev/dri when creating the toolbox.
🚨 Problem: Memory capped at 64GB! 📏
Solution: You're probably using rocm7-nightlies. Switch to rocm-7.2.4 instead!
🚨 Problem: Kernel older than 6.18.4! 📅
Solution: Upgrade your kernel! Older kernels have a bug that causes instability on gfx1151. It's like trying to ride a unicycle with square wheels! 🎡
