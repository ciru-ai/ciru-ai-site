Executive Summary

Verified Activation Facts

Taproot's Speedy Trial activation in 2021 used a roughly three-month signaling window with a 90% threshold, MTP-based start and timeout, version bit 2 signaling, and min_activation_height = 709,632. It was specified in BIP341/BIP343 as effectively a BIP8-style activation mechanism using MTP-based timing, with a compatible BIP8(LOT=true) deployment also defined.

Clarifications

Corrected Wording Points

"Modified BIP9"

Bitcoin Core 0.21.1 describes Speedy Trial as a variation of BIP9 versionbits. BIP341 describes the deployment as versionbits using BIP9 with a lower threshold and min_activation_height. BIP343 describes Speedy Trial as effectively BIP8, except start and timeout used MTP rather than block heights.

"Short Two-Week Window"

The shipped deployment had a roughly three-month signaling period. The two-week concept refers to Bitcoin's 2,016-block retarget period used for threshold evaluation.

"90% Instead Of 95%"

Classical BIP9 mainnet deployments used 95%. Taproot's Speedy Trial used 90%, preserving broad miner support while reducing the risk of malicious activation stalling by rented or unknown hashrate.

min_activation_height

Speedy Trial delayed activation until a set block height even if the threshold was reached early. For Taproot mainnet, that height was 709,632.
