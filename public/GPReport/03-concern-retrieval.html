Layer 3

Turning A Concern Into Candidates

A user concern becomes a broad search mission that pulls from many independent evidence sources.

A concern becomes a search mission.

When the user enters a concern, the system does not stamp that concern onto the archive. It creates an overlay and gathers candidates from many recall nets.

User concern overlay

The concern is versioned and local to the user. The same tweet can matter for one concern and not another.

Many recall nets

Raw text, objective facts, semantic cards, vector neighbors, groups, and group labels can all contribute candidates.

Broad by design

The current example retrieved 9,575 candidates before judging. That is not a mistake. Retrieval is supposed to be generous.

Candidate packets

Each candidate gets a compact evidence packet explaining why it was found. The judge sees the packet, not the whole archive.

Example: A tweet can be found because it is close in vector space, belongs to a relevant group, or has a search-card hint. The model later sees those source families as evidence, not as proof.
