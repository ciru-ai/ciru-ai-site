Why this is different from search.

Ordinary search asks, "Which tweets contain these words?" Ghost Protocol asks a better question: "Which tweets behave like this concern, even when the words are indirect?" The system builds a semantic map, pulls candidates from several recall nets, asks a 35B model to judge the shape of the evidence, and then uses another 35B planning pass to ask the user the one question that can resolve an entire pocket of uncertainty.

The smart question is the compression trick: instead of reviewing hundreds of tweets one by one, the system finds the boundary that can move a whole cluster.
