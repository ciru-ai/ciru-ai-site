Layer 5

The Smart Question Engine

The clever part: one LLM question can collapse a whole pocket of uncertainty into a reusable rule.

This is where the system gets clever.

The smart-question system is not a list of canned questions. It is an LLM-guided uncertainty reducer. It studies the judged facets and asks: what single user answer would clarify the most?

The scaffold builds the puzzle

The deterministic scaffold counts buckets, finds false-positive clusters, gathers examples, and prevents obvious noise from becoming silly questions.

The packet tells the story

The LLM receives the concern, top facets, bucket distributions, examples, ambiguity hints, and proposed rules. It gets enough context to reason, but not the whole archive.

The 35B planner chooses the question

Qwen3.6 35B decides which ambiguity is genuinely user-specific and which clusters should become scope rules instead.

In the accepted run, the LLM rejected weak questions and kept one question that resolves 5 possible matches at once.
